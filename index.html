📖 Installation Guide

        
Choose your platform and follow the steps below.

      

      
    


    

      
      
      
    


    


      
      

        

          
1

          

            
Find the agent you want

            
Browse the platform above, use the search or filters to find the right agent. Each card shows the name, category and what the agent does.

          

        

        

          
2

          

            
Click "Copy Agent"

            
Hit the ⚡ Copy Agent button on the card. The full agent prompt is now in your clipboard.

          

        

        

          
3

          

            
Open Claude.ai and go to Projects

            
Go to claude.ai → click Projects in the left sidebar → click New Project (or open an existing one).

          

        

        

          
4

          

            
Paste into Project Instructions

            
Inside the project, click Edit project instructions → paste the agent you copied → click Save.

          

        

        

          
5

          

            
Start a new chat inside the project

            
Open a new conversation inside the project. The agent is now active — just send your first message and it will respond as a specialist from message one.

          

        

        

          💡 Tip: Create one project per agent to keep things organized. Example: "Ad Copywriter Agent", "Legal Agent", "Finance Agent". You can switch between them in seconds.
        

      


      
      

        

          
1

          

            
Copy the agent from the platform

            
Click ⚡ Copy Agent on the card. The agent content is now in your clipboard.

          

        

        

          
2

          

            
Open your terminal and navigate to your project folder

            
Open the terminal and go to the folder where you want to use the agent. Example: cd ~/my-project

          

        

        

          
3

          

            
Create the .claude/agents folder

            
Run this command to create the agents folder if it doesn't exist yet:

            
mkdir -p .claude/agents

          

        

        

          
4

          

            
Create a .md file and paste the agent

            
Create a new file inside .claude/agents/ with any name. Example: ad-copywriter.md. Open it in any text editor and paste the agent content.

          

        

        

          
5

          

            
Invoke the agent in Claude Code

            
Open Claude Code in your terminal with claude and invoke the agent with a slash command. Example: /ad-copywriter — Claude will activate the specialist automatically.

          

        

        

          💡 Tip: The file name becomes the slash command. finance-agent.md → /finance-agent. Keep names short and lowercase for easy typing.

Copy the agent from the platform

            
Click ⚡ Copy Agent on the card. The full agent prompt is now in your clipboard.

          

        

        

          
2

          

            
Open Cowork and create a new Agent

            
Launch Cowork on your desktop → go to the Agents section → click New Agent or + Add Agent.

          

        

        

          
3

          

            
Paste the agent into the System Prompt field

            
In the agent creation screen, find the System Prompt or Instructions field and paste the content you copied from the platform.

          

        

        

          
4

          

            
Name and save your agent

            
Give the agent a clear name (e.g. "Ad Copywriter", "Legal Assistant") and click Save. It will appear in your agent list.

          

        

        

          
5

          

            
Select and run the agent

            
From your agent list, click the agent you just created and start a new task. The specialist context is already active — just describe what you need.

          

        

        

          💡 Tip: In Cowork you can attach files directly to the agent session. Combine the specialized agent with your own documents for even sharper, context-aware results.
